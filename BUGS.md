# Баг-репорты по результатам тестирования API

Тестирование на реальном API `https://qa-internship.avito.com`.
Обнаружено 5 багов. Часть тестов падает именно из-за этих проблем на стороне сервера.

## BUG-001: Созданное объявление возвращает id = null
- **Тесты**: `test_tc01`, `test_tc05`, `test_tc08`
- **Шаги**: POST /api/1/item с валидными данными
- **Ожидаемый результат**: непустой `id`
- **Фактический результат**: `id` равен `null`
- **Приоритет**: High

## BUG-002: GET несуществующего объявления возвращает 400 вместо 404
- **Тест**: `test_tc06`
- **Шаги**: GET /api/1/item/nonexistent-id-99999
- **Ожидаемый результат**: 404
- **Фактический результат**: 400
- **Приоритет**: Medium

## BUG-003: GET статистики несуществующего объявления возвращает 400 вместо 404
- **Тест**: `test_tc09`
- **Шаги**: GET /api/1/statistic/nonexistent-id-99999
- **Ожидаемый результат**: 404
- **Фактический результат**: 400
- **Приоритет**: Medium

## BUG-004: GET по sellerID игнорирует фильтрацию
- **Тест**: `test_tc07`
- **Шаги**: создать объявление с sellerID, затем GET /api/1/{sellerID}/item
- **Ожидаемый результат**: возвращается 1 объявление (только что созданное)
- **Фактический результат**: возвращается более 1000 объявлений, принадлежащих разным sellerID; фильтр по sellerID не применяется
- **Приоритет**: High

## BUG-005: Отсутствует валидация входных данных
- **Тесты**: `test_tc02`, `test_tc03`, `test_tc04`, `test_tc10`
- **Шаги**: POST с отсутствующим name / отрицательной ценой / пустым name / sellerID вне диапазона
- **Ожидаемый результат**: 400
- **Фактический результат**: API принимает некорректные данные
- **Приоритет**: High
