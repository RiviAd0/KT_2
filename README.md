# Тестовое задание QA-стажёр Авито (осень 2025)

## Что это
Решение тестового задания для стажёра QA в Авито, осенняя волна 2025.
Репозиторий содержит результаты Задания 1 (поиск багов на скриншоте) и Задания 2.1 (тест-кейсы и автотесты API).

## Ссылка на задание
https://github.com/avito-tech/tech-internship/tree/main/Tech%20Internships/QA/QA-trainee-assignment-autumn-2025

## Что сделано
- **Задание 1**: найдено 9 багов на скриншоте карьерного сайта, каждому присвоен приоритет и обоснование (см. `task1_bugs.md`).
- **Задание 2.1**: составлены тест-кейсы для 4 ручек API (см. `TESTCASES.md`), автоматизированы на Python + pytest (см. `test_api.py`), описаны найденные баги (см. `BUGS.md`).

## Что не сделано
- **Задание 2.2 (E2E UI-тесты)**: не выбрано, так как по условию нужно выбрать один вариант из двух.
- **Нагрузочное тестирование и тесты безопасности**: не входят в объём тестового задания.
- **Полное покрытие всех граничных случаев API**: обеспечиваю прохождение основного сценария и части негативных кейсов в рамках отведённого времени.

Требуется Python 3.10+
