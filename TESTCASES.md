# Задание 2.1 — Тест-кейсы API микросервиса объявлений

Host: https://qa-internship.avito.com

## TC-01: Создание объявления с валидными данными
- **Тип**: позитивный
- **Шаги**: POST /api/1/item с телом `{"sellerID": <уникальный 111111-999999>, "name": "Test Item", "price": 1000, "statistics": {"likes": 0, "viewCount": 0, "contacts": 0}}`
- **Ожидаемый результат**: код 200, ответ содержит `id` (не null), поля совпадают с отправленными
- **Приоритет**: High

## TC-02: Создание объявления без поля name
- **Тип**: негативный
- **Шаги**: POST /api/1/item с телом без `name`
- **Ожидаемый результат**: код 400, тело ответа содержит поле `message` с указанием на отсутствующее обязательное поле `name`
- **Приоритет**: High

## TC-03: Создание объявления с отрицательной ценой
- **Тип**: негативный
- **Шаги**: POST /api/1/item с `"price": -100`
- **Ожидаемый результат**: код 400
- **Приоритет**: Medium

## TC-04: Создание объявления с пустой строкой в name
- **Тип**: негативный
- **Шаги**: POST /api/1/item с `"name": ""`
- **Ожидаемый результат**: код 400, тело ответа содержит поле `message` о недопустимости пустого значения
- **Приоритет**: Medium

## TC-05: Получение объявления по существующему ID
- **Тип**: позитивный
- **Предусловие**: создано объявление (TC-01)
- **Шаги**: GET /api/1/item/{id}
- **Ожидаемый результат**: код 200, данные совпадают с созданными
- **Приоритет**: High

## TC-06: Получение объявления по несуществующему ID
- **Тип**: негативный
- **Шаги**: GET /api/1/item/nonexistent-id-99999
- **Ожидаемый результат**: код 404
- **Приоритет**: High

## TC-07: Получение всех объявлений по sellerID
- **Тип**: позитивный
- **Предусловие**: создано объявление с уникальным sellerID
- **Шаги**: GET /api/1/{sellerID}/item
- **Ожидаемый результат**: код 200, возвращается массив, содержащий созданное объявление
- **Приоритет**: High

## TC-08: Получение статистики по существующему item id
- **Тип**: позитивный
- **Предусловие**: создано объявление
- **Шаги**: GET /api/1/statistic/{id}
- **Ожидаемый результат**: код 200, статистика (likes, viewCount, contacts)
- **Приоритет**: High

## TC-09: Получение статистики по несуществующему item id
- **Тип**: негативный
- **Шаги**: GET /api/1/statistic/nonexistent-id-99999
- **Ожидаемый результат**: код 404
- **Приоритет**: Medium

## TC-10: Создание объявления с sellerID вне диапазона
- **Тип**: негативный
- **Шаги**: POST /api/1/item с `"sellerID": 100`
- **Ожидаемый результат**: код 400
- **Приоритет**: Medium
